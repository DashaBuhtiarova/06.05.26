Css



















































Каждый тег а является сыном для каждого тега li,а каждый тег li является сыном для каждого тега ul,а тег b является сыном для тега a,так же теги li,a,b являются детьми для тега ul.


Для тега table теги tr и td являются дочерними,а для каждого тега tr теги td являются дочерними,теги tr и table являются родителями для тега td.


Для тега p теги b,i и a являются дочерними,первый тег i является родителем для тега b,а для b тег i является родителем,тег a является додителем для второго тега i,а для второго тега i тег a является родителем.


У тега b есть непосредственный родитель i,дедушка тег a и прадедушка тег p.


Текст у тега b будет синего цвета.


Текст у тега b будет красного цвета.


Текст у тега b будет красного цвета.


Текст у тега li будет синего цвета.


Текст у тега li будет красного цвета.


Текст у тега i будет зелёного цвета.


Текст у тега i будет красного цвета.


















Потому что тег li является дочерним для тега ul
